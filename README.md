# crowdsensing-wot-android-app
 Android application to partecipate in crowdsensing campaign, using a WOT Servient implemented in Java following the W3C WOT specifications. Part of Davide Tinti Thesis

## iOS

Nella cartella [`ios/`](ios/) è disponibile il porting nativo per iOS
(Swift/SwiftUI), compatibile con lo stesso backend (proxy node-wot, Thing
Description Directory e broker MQTT) senza modifiche lato server. Vedi
[`ios/README.md`](ios/README.md) per istruzioni di build e limitazioni.
